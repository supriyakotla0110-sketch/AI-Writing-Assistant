# AI Writing Assistant

## Overview

AI Writing Assistant is a desktop application built using Python, CustomTkinter, and Natural Language Processing (NLP). The application helps users improve writing quality through automatic spell correction, sentiment analysis, keyword extraction, and writing statistics.

## Features

* Spell Correction
* Sentiment Analysis
* Keyword Extraction
* Word Count
* Character Count
* Reading Time Estimation
* Writing Quality Score
* Save Report Functionality

## Technologies Used

* Python
* CustomTkinter
* TextBlob
* NLP

## Installation

pip install -r requirements.txt

## Run

python app.py
